# 🎮 Garlic Tiger — Pokemon Gold (GBC) 완벽 레플리카 리메이크 프롬프트

## 프로젝트 개요

"Garlic Tiger"를 **포켓몬 골드 (게임보이 컬러)와 시각적으로 구분 불가능한 수준의 레플리카**로 리메이크한다. 게임플레이, UI, 타일맵, 스프라이트, 텍스트 박스, 배틀 화면, 메뉴 시스템 모두 포켓몬 골드와 **픽셀 단위로 동일**하게 구현한다. 유일한 차이점: 주인공이 포켓몬 트레이너 대신 **호랑이**이고, 포켓몬 대신 **한국 문화 퀴즈 NPC**를 만난다.

---

## 1. 하드웨어 사양 (GBC 정확 재현)

### 화면
- **해상도**: 160×144 픽셀 (비율 10:9)
- **스케일링**: CSS로 정수배 확대 (×2 = 320×288, ×3 = 480×432, ×4 = 640×576)
- **렌더링**: `image-rendering: pixelated` / `crisp-edges` 적용
- **Phaser 설정**: `pixelArt: true`, `roundPixels: true`
- **절대 안티앨리어싱 없음** — 모든 그래픽이 깨끗한 정수배 픽셀

### 타일 시스템
- **기본 타일**: 8×8 픽셀
- **화면 타일 그리드**: 20×18 타일 (= 160×144)
- **배경 맵**: 32×32 타일 (256×256 픽셀) — 스크롤 가능
- **화면에 보이는 영역**: 배경 맵의 20×18 부분만 표시
- 오버월드 오브젝트(캐릭터, 나무, 건물)는 **16×16 픽셀 (2×2 타일)** 또는 그 이상

### 컬러 시스템
- **15-bit RGB** (채널당 5비트, 0-31 범위)
- **팔레트**: BG 8개 × 4색 + Sprite 8개 × 3색(+투명)
- **동시 표시 색상**: 최대 56색
- **총 가용 색상**: 32,768색
- 5-bit → 8-bit 변환: `value8 = Math.round(value5 * 255 / 31)`

## 3. 오버월드 구현

### 3-1. 타일맵 구조

```
화면 크기: 20×18 타일 (160×144 px)
맵 크기: 32×32 타일 이상 (스크롤)
타일 렌더링: 8×8 픽셀 기본 단위
```

**타일 종류** (포켓몬 골드 정확 재현):

| 타일 | 크기 | 팔레트 | 설명 |
|------|------|--------|------|
| 잔디 | 8×8 | Green | 밝은 초록 배경, 풀 텍스처 패턴 |
| 높은 풀 (Tall Grass) | 8×8 | Green | 진한 초록, V자 풀잎 패턴 (포켓몬과 동일) |
| 길 (Path) | 8×8 | Brown | 밝은 갈색 단색 |
| 물 (Water) | 8×8 | Water | 애니메이션 (2프레임 반복) |
| 나무 (Tree) | 16×24 | Green | 3×2 타일 — 둥근 잎 + 기둥 |
| 건물 벽 | 다양 | Gray | 포켓몬 골드 스타일 가옥 |
| 지붕 | 다양 | Roof | 마을마다 색상 다름 |
| 문 | 8×16 | Gray | 건물 입구 |
| 울타리 | 8×8 | Brown | 가로/세로 울타리 |
| 표지판 | 8×16 | Yellow | 읽기 상호작용 가능 |

### 3-2. 캐릭터 스프라이트 (호랑이)

**크기**: 16×16 픽셀 (2×2 타일)
**방향**: 상/하/좌/우 (4방향)
**걸음 애니메이션**: 방향별 3프레임 (기본 → 왼발 → 기본 → 오른발)

```
총 필요 프레임:
  - 아래 보기 (기본)       16×16
  - 아래 걷기 왼발         16×16
  - 아래 걷기 오른발       16×16
  - 위 보기               16×16
  - 위 걷기 왼발           16×16
  - 위 걷기 오른발         16×16
  - 옆 보기               16×16 (좌우 미러링)
  - 옆 걷기 왼발           16×16
  - 옆 걷기 오른발         16×16
```

**호랑이 스프라이트 디자인 가이드**:
- 포켓몬 골드의 주인공(히비키/크리스)와 **동일한 비율과 실루엣**
- 머리 크기 = 전체 높이의 약 50% (8×8 영역)
- 몸통 = 하단 8×8 영역
- **주황/검정 줄무늬** 호랑이 패턴
- 팔레트: 투명 / 주황 #F89838 / 검정 줄무늬 #383838 / 흰색 배 #F8F8F8

### 3-3. 이동 시스템

```javascript
// 포켓몬 골드와 동일한 이동:
TILE_SIZE = 8;            // 8px 기본 타일
SPRITE_SIZE = 16;         // 16px 캐릭터 (2×2 타일)
WALK_SPEED = 2;           // 프레임당 2px 이동 (8프레임에 1타일 이동)
MOVE_FRAMES = 8;          // 16px 이동에 8프레임

// 이동 사이클 (매 16px 이동):
// 프레임 0-3: 걷기 A 스프라이트 표시, 2px씩 이동
// 프레임 4-7: 걷기 B 스프라이트 표시, 2px씩 이동
// 프레임 8: 기본 스프라이트로 복귀, 다음 타일 도착

// 1타일 = 16px (2×2 기본타일 단위로 이동)
```

### 3-4. NPC 스프라이트

**크기**: 16×16 픽셀 (플레이어와 동일)
**동작**: 제자리 회전 (랜덤 방향 전환) 또는 고정 방향

5명의 NPC:
1. **식당 아줌마** — Brown NPC 팔레트, 앞치마 착용
2. **편의점 알바** — Blue NPC 팔레트, 조끼 착용
3. **지하철 할머니** — Red NPC 팔레트, 한복 스타일
4. **박팀장** — Blue NPC 팔레트, 넥타이 착용
5. **성수동 힙스터** — Green NPC 팔레트, 비니 착용

## 5. 대화 시스템 (포켓몬 골드 정확 재현)

### 5-1. 대화창

```
위치: 화면 하단 4타일 (y=112~143)
크기: 160×32 px (전체 폭)
테두리: 포켓몬 골드 대화창 프레임
  - 1px 검정 외곽선
  - 1px 흰색 내부 선
  - 실제 테두리 = 2px 두께

텍스트:
  - 8×8 px 타일 기반 폰트 (Press Start 2P 대체 사용)
  - 최대 2줄
  - 줄당 최대 18글자 (양쪽 패딩 1타일씩)
  - 한글 = 글자당 2타일 폭 (8px × 2 = 16px)

타이핑 애니메이션:
  - 글자 하나씩 나타남 (타자기 효과)
  - 속도: ~30ms/글자
  - 텍스트 완료 시 ▼ 커서 깜빡임 (다음 페이지 표시)
  - A버튼으로 스킵 가능
```

### 5-2. 선택지 UI

```
위치: 화면 우측에 세로 메뉴 박스 팝업
  ┌────────┐
  │▶ 네    │
  │  아니오 │
  └────────┘

## 7. 장면(Scene) 구성

### Scene 1: BootScene
- LocalNomad 로고 → 페이드 인/아웃
- 포켓몬 골드의 게임프리크 로고 화면과 동일한 타이밍

### Scene 2: TitleScene
- **포켓몬 골드 타이틀 화면과 동일한 레이아웃**
- 상단: 호랑이 스프라이트 (전신, 64×64 이하)
- 중앙: "GARLIC TIGER" 타이틀 (포켓몬 로고 위치)
- 하단: "PRESS START" 깜빡임
- 배경: 단색 또는 그라데이션 (포켓몬 골드 스타일)

### Scene 3: IntroScene
- 오박사 → 호랑이 소개 형식
- 포켓몬 골드의 오박사 인트로와 **동일한 레이아웃**
- 화면 중앙에 NPC/호랑이 스프라이트
- 하단에 대화창 (포켓몬 스타일)
- "호랑이가 한국에 들어가려면 마늘 5개가 필요합니다"

### Scene 4: OverworldScene (핵심)
- **스크롤링 맵** (포켓몬 골드와 동일)
  - 플레이어는 항상 화면 중앙
  - 맵이 플레이어 주위를 스크롤
  - 맵 가장자리에서만 플레이어가 화면 중앙에서 벗어남
- **D-패드 컨트롤**: 키보드 방향키 + 모바일 터치 D-패드
- **높은 풀 랜덤 인카운터**: 3걸음 후 25% 확률
- **NPC 대화**: A버튼으로 상호작용
- **마늘 카운터**: 화면 상단 HUD (포켓몬의 배지 카운터 스타일)

### Scene 5: QuizScene (배틀 화면)
- 위 섹션 4의 배틀 레이아웃 **정확히** 사용
- NPC 앞모습 스프라이트 56×56
- 호랑이 뒷모습 스프라이트 48×48
- 퀴즈 선택지 = 배틀 기술 선택 UI
- 정답 시 → TransformScene
- 오답 시 → 대화 + 다시 시도

### Scene 6: TransformScene
- 포켓몬 진화 화면과 동일
- 화면 중앙에 호랑이 스프라이트
- 흰색 플래시 → 변환 애니메이션
- 배경: 단색 (진화 화면처럼)
- 5단계 변환:
  1. 털 빠짐
  2. 몸 늘어남
  3. "TH" 발음 불가 (혀 변환)
  4. 검은 머리
  5. 인사 반사 (최종)

### Scene 7: VictoryScene
- 마늘 5개 수집 완료
- 한옥 게이트 열림 애니메이션
- 포켓몬 리그 클리어 느낌

### Scene 8: ScrollScene
- 두루마리 획득 + 이메일 수집
- 포켓몬 명예의 전당 느낌

### Scene 9: GameOverScene
- 공유 기능 + 다시 시작
- 포켓몬 "이름을 남기시겠습니까?" 스타일

## 8. 사운드 (포켓몬 골드 스타일)

```
Web Audio API 기반:
- 4채널 (GB 사운드 칩 재현)
  - Square Wave 1 (멜로디)
  - Square Wave 2 (하모니)
  - Wave Channel (베이스)
  - Noise Channel (드럼/효과)

사운드 효과:
  - 메뉴 커서 이동: 짧은 blip (440Hz, 20ms)
  - 선택 확인: 중간 blip (880Hz, 30ms)
  - 대화 텍스트: 타이핑 blip (글자마다)
  - 인카운터 진입: 와일드 포켓몬 등장음 스타일
  - 정답: 팡파르 (짧은 멜로디)
  - 오답: 낮은 buzzer
  - 진화/변환: 포켓몬 진화 사운드 스타일
```

## 9. 모바일 컨트롤 (터치 UI)

D-패드 (오버월드):
  위치: 화면 좌하단
  크기: 48×48 px (확대 후 기준)
  스타일: 반투명, GB 십자키 모양

  ┌─────────┐
  │    ▲    │
  │ ◀  ●  ▶ │
  │    ▼    │
  └─────────┘

  위치: 화면 우하단
  A: 확인/대화 (포켓몬 A버튼 위치)

  배치:
    [B]  [A]   ← 포켓몬 GB와 동일한 대각선 배치

  화면 하단 중앙 (작은 버튼)

## 10. 텍스트/폰트 시스템

### 폰트
- **기본**: "Press Start 2P" (Google Fonts) — GBC 폰트 유사
- **크기**: 항상 8px 기준 (스케일링으로 확대)
- **렌더링**: 비트맵 폰트처럼 깨끗하게 (안티앨리어싱 없음)

### 한글 처리
- 한글은 타일 2개 폭 (16px) 차지
- 영문은 타일 1개 폭 (8px)
- 줄당 최대: 영문 18자 / 한글 9자 (혼합 시 계산)
- 줄바꿈은 단어 단위

### 텍스트 크기 (스케일 전 원본 해상도 기준)
```
대화 텍스트: 8px
메뉴 텍스트: 8px
타이틀: 8px (대문자)
NPC 이름: 8px
HP 수치: 8px
모든 텍스트가 8px — 이것이 GBC의 한계이자 미학
```

## 11. 기술 스택

```
프레임워크: Phaser 3.90+ (pixelArt: true)

### Phaser 설정

```javascript
const config = {
  type: Phaser.AUTO,
  width: 160,    // GBC 원본 해상도
  height: 144,   // GBC 원본 해상도
  pixelArt: true,
  roundPixels: true,
  scale: {
    mode: Phaser.Scale.FIT,
    autoCenter: Phaser.Scale.CENTER_BOTH,
  },
  physics: {
    default: 'arcade',
    arcade: { gravity: { y: 0 } }
  },
  scene: [BootScene, TitleScene, IntroScene, OverworldScene,
          QuizScene, TransformScene, VictoryScene, ScrollScene, GameOverScene]
};
```
